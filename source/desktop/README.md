# Falcon Time — агент снимков экрана (desktop)

Electron-приложение для macOS. Сотрудник входит тем же логином и личным кодом,
что и в кабинете Falcon Time, даёт разрешение macOS «Запись экрана», и приложение
раз в 3 минуты снимает основной монитор и отправляет кадр в кабинет.

Это второй агент рядом с расширением Chrome: расширение считает сессии активности
в ChatGPT, этот агент делает снимки экрана. Он их не заменяет и часы по кадрам не считает.

## Запуск (разработка)

```sh
cd source/desktop
npm install
npm start
```

По умолчанию агент подключается к `http://127.0.0.1:5173` (локальный dev-кабинет).
Другой адрес вводится в окне входа или через переменную `FALCON_CABINET`.

## Сборка под macOS (Apple Silicon, arm64)

```sh
cd source/desktop
npm install
npm run dist          # electron-builder --mac --arm64 → dist/*.dmg
```

Для распространяемой подписанной сборки нужны Apple Developer ID и нотаризация
(настраиваются оператором в окружении electron-builder). Разрешение «Запись экрана»
TCC выдаётся пользователем в Системных настройках при первом запуске.

## Что приложение делает

- Вход: `POST /api/login` тем же логином и личным кодом; сессия (cookie
  `falcon_profile`) хранится локально в профиле приложения и переживает перезапуск.
- Первый кадр — сразу после старта, далее строго раз в 180000 мс. Пропущенные
  интервалы (сон, пауза) не досылаются пачкой.
- Кадр: `desktopCapturer.getSources({ types: ['screen'], thumbnailSize: { width: 1280, height: 720 } })`,
  основной монитор, JPEG качества ~60.
- Иконка в строке меню: текст «Falcon Time снимает экран каждые 3 минуты», время
  последнего кадра, состояние, кнопки «Пауза» и «Выйти».
- Без паузы и без разрешения «Запись экрана» кадры не снимаются и не отправляются.
- Если кабинет недоступен, кадр остаётся в локальной очереди (`<userData>/queue`) и
  уходит при следующей удачной синхронизации. Идентификатор кадра постоянный,
  поэтому повторная отправка не создаёт второй записи.

## Чего приложение НЕ делает

- Не прячется: нет stealth-режима и скрытых окон, TCC не обходится.
- Не читает клавиши, буфер обмена и окна других приложений по названию.
- Не отправляет снимки никуда, кроме указанного кабинета.

## Где лежат данные

- Сессия и очередь: каталог `app.getPath('userData')` (на macOS —
  `~/Library/Application Support/Falcon Time`).
- Снимки на сервере: метаданные в SQLite, файлы JPEG —
  `{FALCON_DATA_DIR или data}/shots/{person_id}/{id}.jpg`.
