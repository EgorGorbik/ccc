FALCON TIME — Chrome / Edge
1. Распакуйте этот архив.
2. Откройте chrome://extensions (или edge://extensions), включите Developer mode и Load unpacked. Выберите эту папку.
3. Откройте https://falconai.time и войдите через целевой аккаунт ChatGPT, затем своим личным кодом. Заполните анкету.
4. Оставьте кабинет открытым. В расширении нажмите Подключить.
5. Откройте чат в целевом аккаунте ChatGPT. Выберите проект в расширении. Действия в чате начнут учёт автоматически.
Телефон: этот же кабинет открывается в браузере и добавляется на главный экран.
Учитываются только действия в видимой вкладке ChatGPT. Ответ ИИ и открытый кабинет не продлевают сессию.
Через 30 минут без действий рассчитывается выход. Эти 30 минут включаются в итог.
Личные коды и пароль ChatGPT — разные вещи. Пароль ChatGPT расширение не получает.
Смена аккаунта ChatGPT не распознаётся автоматически. Используйте отдельный профиль браузера для целевого аккаунта.
При потере связи события остаются в очереди текущего сотрудника, не присваиваются другому. Старше 7 дней требуется проверка.
Код расширения проверен статически; реальное подключение требует установки на компьютере сотрудника.
